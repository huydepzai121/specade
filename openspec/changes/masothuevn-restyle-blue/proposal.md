## Why

The current masothuevn.org homepage uses a Teal (#0D9488) color scheme. The client wants to switch to Blue (#0685D6) and adopt a more traditional Vietnamese business directory style — similar to DauThau.info — with a full-width blue navigation bar, classic form-based search layout, and a more information-dense presentation.

## What Changes

- Replace entire color palette from Teal to Blue (#0685D6 primary)
- Restyle header: add full-width blue navigation bar below the logo bar (DauThau.info style)
- Restyle hero: replace gradient hero with a more traditional search form section
- Adjust all accent colors, hover states, and active states to blue palette
- Update Pencil design variables and HTML/CSS to match

## Capabilities

- `blue-restyle`: Complete visual restyle from Teal to Blue (#0685D6), including header nav bar, search form layout, and all color tokens
