# Licensing

Spec ADE uses an offline license system based on digital signatures. Licenses are tied to a specific machine via hardware fingerprint.

## Activation flow

1. Launch Spec ADE — if no license is active, the activation page appears
2. Note the **machine fingerprint** displayed on the activation page
3. Contact your license administrator to generate a license for your machine
4. You will receive a `.lic` file or a JWT string
5. Paste the JWT or upload the `.lic` file on Spec ADE's activation page

## Offline verification

Licenses are verified entirely offline — no network calls needed. The license token contains:
- Machine fingerprint (must match current machine)
- Organization name
- Expiration date
- Digital signature

If the fingerprint matches and the token hasn't expired, the license is valid.
