# Licensing

Spec ADE uses an offline license system based on Ed25519 digital signatures and JWT tokens. Licenses are tied to a specific machine via hardware fingerprint.

## How it works

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ License Portal│────▶│  .lic file   │────▶│  Spec ADE    │
│ (generates)  │     │  (JWT token) │     │  (activates) │
└──────────────┘     └──────────────┘     └──────────────┘
```

1. **Portal generates keypair** — Ed25519 private/public key pair stored in `~/.config/spec-ade-portal/`
2. **Public key embedded in binary** — copied to `spec-ade-api/keys/license-public.key` before building
3. **Portal signs licenses** — JWT tokens signed with the private key
4. **Spec ADE verifies** — the embedded public key validates license tokens offline

## Activation flow

1. Launch Spec ADE — if no license is active, the activation page appears
2. Note the **machine fingerprint** displayed on the activation page
3. Open the License Portal (`just portal-run` → `http://localhost:3000`)
4. Enter the machine fingerprint and organization name
5. Select a plan duration
6. Download the `.lic` file or copy the JWT string
7. Paste the JWT or upload the `.lic` file on Spec ADE's activation page

## Key distribution

For building Spec ADE with license verification:

```bash
# 1. Run the portal to generate keys (first run only)
just portal-run

# 2. Copy public key to the API project
cp ~/.config/spec-ade-portal/public.key spec-ade-api/keys/license-public.key

# 3. Build — public key is embedded at compile time
just build-release
```

## License portal data

| Item | Location |
|------|----------|
| Private key | `~/.config/spec-ade-portal/private.key` |
| Public key | `~/.config/spec-ade-portal/public.key` |
| License database | `~/.config/spec-ade-portal/licenses.db` (SQLite) |

## Offline verification

Licenses are verified entirely offline — no network calls needed. The JWT token contains:
- Machine fingerprint (must match current machine)
- Organization name
- Expiration date
- Signature (Ed25519)

The embedded public key verifies the signature. If the fingerprint matches and the token hasn't expired, the license is valid.
