# Giấy phép

Spec ADE sử dụng hệ thống giấy phép offline dựa trên chữ ký số. Giấy phép được gắn với máy cụ thể qua hardware fingerprint.

## Quy trình kích hoạt

1. Khởi chạy Spec ADE — nếu chưa có giấy phép, trang kích hoạt xuất hiện
2. Ghi nhận **machine fingerprint** hiển thị trên trang kích hoạt
3. Liên hệ quản trị viên giấy phép để tạo license cho máy của bạn
4. Bạn sẽ nhận được file `.lic` hoặc chuỗi JWT
5. Dán JWT hoặc upload file `.lic` trên trang kích hoạt Spec ADE

## Gói

| Gói | Thời hạn | Ngày |
|-----|----------|------|
| 1 tháng | 30 ngày | 30 |
| 1 năm | 365 ngày | 365 |
| 3 năm | 1095 ngày | 1095 |
| 5 năm | 1825 ngày | 1825 |

## Xác minh offline

Giấy phép được xác minh hoàn toàn offline — không cần gọi mạng. Token giấy phép chứa:
- Machine fingerprint (phải khớp máy hiện tại)
- Tên tổ chức
- Ngày hết hạn
- Chữ ký số

Nếu fingerprint khớp và token chưa hết hạn, giấy phép hợp lệ.
