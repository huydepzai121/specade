# Welcome to Spec ADE

Spec ADE is a full-stack GUI for AI coding assistants. It gives you a unified workspace where multiple AI agents operate in parallel — each with its own terminal, worktree, and permissions — while you stay in control from a single interface.

## What makes Spec ADE different

- **Multi-agent workspace** — Run a fleet of AI agents (called Claws) against a single project. Review bots, doc writers, test generators — each in isolation, all under one roof.
- **Git worktrees built in** — Every agent gets its own worktree. Refactor in parallel without stepping on the main branch.
- **Skills system** — Package any prompt + tooling into a reusable Skill. Drop it on any Claw. Versioned and shareable.
- **Terminal-native** — Integrated PTY terminal with full xterm emulation. Slash commands, auto-approve, and real-time token usage.
- **JetBrains-inspired UI** — Pane system with 9 tab kinds, drag-resize, layout presets, and keyboard shortcuts that feel familiar.

## Tech stack

| Layer | Technology |
|-------|-----------|
| Frontend | Vue 3 + Quasar v2 + Pinia + TypeScript |
| Backend | Rust 2024 + Axum + portable-pty + tokio |
| Desktop | Tauri v2 (sidecar) |
| Distribution | npm (`@spec-ade/cli`), single binary |
